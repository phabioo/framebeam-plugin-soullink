# FrameBeam Plugin: SoulLink

SoulLink/Nuzlocke runs for FrameBeam: rules, detection, team and route views, Hub run board.

Status: **planned, nothing implemented.**

Requires FrameBeam with plugin API v1 (FrameBeam 0.11, planned). Part of [FrameBeam](https://github.com/phabioo/framebeam); plugin interface: `docs/architecture/12-plugins.md` there. Plan: [docs/roadmap.md](docs/roadmap.md). UI design (screens 5a to 5i): [docs/design/](docs/design/README.md).
